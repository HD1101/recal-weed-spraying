### 0. 性质

D008–D010 都是事后分析：在主分析、D005–D007 的结果以及审阅意见已知之后提出。它们不改变冻结计划（SHA256 e80795012ce4d4b492a0152a5e89acebe8246703c2fd579f7b4b98f64a7e81f9）和已有结果，在论文中一律标注 post hoc。三项分析的全部设定在本文件中事先写定，计算开始后不再增减取值。

### 1. 共同设定

- 数据：v1.1.0 中已有的导出预测和真值框；27 个训练配置（3 个轮换 × 3 个检测器 × 3 个训练种子）及其全部目标。
- 抽样：沿用正式分析的抽样序列（同一随机种子、同样的 200 次抽样、5 档 K、理想划分和分组划分）。不重新抽样。
- 汇总口径：与主分析相同（每个种子内对 200 次抽样取平均，再对 3 个种子等权平均；同时给出种子的最小值和最大值）。关键数字另给蒙特卡洛标准误，算法同 D007（SD/√200）。
- 判读：只做描述，不做显著性检验，不据此对检测器排名。
- 回归检查（必须先通过）：新代码在 n = 4、α = 0.10、覆盖判据为"完全包含"时，主 CRC 和源阈值的 M、A、退回全喷次数必须与 `MAIN_TABLE_N4_GROUPED_K20_K50.csv` 及对应的全量结果逐格一致（绝对差 ≤ 1e-9）。不一致则停止并报告。

### 2. D008：喷头数量

- 问题：喷带划分更细时，达到同一漏喷目标所需的模拟喷洒面积是否下降，下降多少。
- 取值：n = 8 和 n = 16，只有这两个值。喷带按图像高度等分（H/n），与主分析的定义相同。
- 方法：源阈值、主 CRC（B = 1，α = 0.10）、真值框触发参照。其余方法不重算。
- 指标：M、A、退回全喷次数、WCR；真值框参照只报 A。
- 报告重点：分组划分、K = 50 下，n = 4、8、16 的对照；DETR 类检测器在 LB 留出田块上的 A 范围；主 CRC 与真值框参照的面积差。其余 K 和理想划分的结果进补充表。
- 边界：外部数据集的相机几何是假设的，喷带对应的实际宽度未知；n = 8、16 是图像平面上的划分，不代表具体机型。

### 3. D009：风险目标

- 问题：允许的平均漏喷率不同（更严或更宽）时，达标格数、喷洒面积和退回全喷次数如何变化。
- 取值：α = 0.05 和 α = 0.20，只有这两个值；n = 4。
- 方法：只做主 CRC（B = 1）。按棵 CRC、HB-LTT 和 naive recalibration 不重算（它们的参数与 α 的关系需要另行设定，不在本项范围内）。
- 指标：平均 M ≤ α 的格数、A、退回全喷次数、K′。
- 报告重点：分组划分下 K = 20、50、100 的达标格数和 A 的范围，与 α = 0.10 的已有结果并列。
- 必须写明：式 (8) 的最小 K′ 在 α = 0.05 时为 19，在 α = 0.20 时为 4；因此 α = 0.05 时 K = 5、10 必然全部退回全喷。

### 4. D010：覆盖判据的敏感性

- 问题：把"真值框完全落在喷洒区域内才算覆盖"放宽后，漏喷率和主要结论是否改变。
- 取值：覆盖比例阈值 0.9，只有这一个值（原判据相当于 1.0）；n = 4。
- 定义：一株杂草算被覆盖，当且仅当其真值框面积中至少 90% 落在各喷带喷洒区域的并集内。并集按喷带分别求交后相加，避免重叠区域重复计数。
- 方法：源阈值和主 CRC（B = 1，α = 0.10）。主 CRC 的校准损失和测试评估都用新判据（即在新判据下重新选阈值）。
- 指标：M、A、退回全喷次数、WCR。
- 报告重点：分组划分 K = 20、50、100 下的达标格数与原判据对照；各格 M 的变化范围；重新选出的阈值导致的 A 变化。
