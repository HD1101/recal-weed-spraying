# 已确认的喷洒几何与指标

依据：[Darbyshire 等（2023）第 3.2 节](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2023.1183277/full)与[图 2](https://www.frontiersin.org/files/Articles/1183277/xml-images/fpls-14-1183277-g002.webp)。水平居中已由负责人确认，本次保留原实现。

车辆沿图像宽度行进，按高度等分 n=1/2/3/4 条横向条带。类别 1、置信度 >= t 的预测框与条带正面积相交时，生成条带高度 H/n、宽度 max(H/n, 框宽) 的区域；以框水平中心为中心，裁剪到图像内，不平移补足宽度。

采用连续像素 xyxy 坐标，条带高度保留分数。每条带内求水平区间并集；重叠不重复计面积，接触区间可以合并，正间隙不填补。真值杂草框跨过的每条带都必须完全覆盖，多个区域可以共同覆盖一棵。仅碰条带边界不额外触发。

绝对 1e-9 像素容差仅用于输入边界舍入和包含关系，不用于填补间隙。没有按 IoU、框中心或部分覆盖替代整框覆盖，也不重新执行 NMS。

- 按棵 WCR：先跨图求喷到数与总杂草数，再相除。
- 面积占比：先跨图求并集面积与原图面积，再相除，所有图都计入。
- 按张平均 WCR：仅在有真值杂草的图上取算术平均。
- 全部 GT 无杂草时两个 WCR 为 `null`，全喷也保留此分母约定。

旧三图演示保留，用于解释 20% 按棵 WCR 与 25% 按张 WCR 的口径差异，不承担校准实验。
